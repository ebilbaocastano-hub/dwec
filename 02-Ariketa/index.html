Ariketa 2

Zer desberdintasuna dago var eta let artean?

var funtzioan deklaratzen da beti erabiltzeko eta let blokean deklaratzeko da.


Eta let eta const artean?

let blokean deklaratzeko da eta const konstanteak deklaratzeko balio du, adibidez pi, beti zenbaki berdina da.


Zer diferentzia dago == eta === artean?

== operadoreak bariableak aldatzeko d, adibidez, 5 == "5" erantzuna true da, baina 5 === "5" erantzuna false da (int eta string).


Zer desberdintasuna dago while eta do-while artean?

While ez da exekutatuko beti eta do- while exekutatuko da behin gutxienez.


Ordeztu if hau operatzaile ternario batekin: let puntos = 75; let rol; if (puntos ›= 100) { rol = "VIP"; } else { rol = "Member"; }

let puntos = 75; let rol; rol = (puntos >=100) ? "VIP" : "Member";


Ordeztu kate hau letra-sarrera literalekin: let nombre = "Juan"; let puntos = 85; let rol = "Member"; console.log("Usuario: " + nombre + " | Puntos: " + puntos + " | Rol: " + rol);

let nombre = "Juan"; let puntos = 85; let rol= "Member"; console.log('Nombre: ${nombre} Puntos: ${puntos} Rol: ${rol}')


Zergatik aukeratu behar da txantiloi literalak "+" erabili baino?

Irakurtzeko errazagoa delako eta erabilera errazagoa delako.
